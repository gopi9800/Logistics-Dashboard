# Swift Route Logistics Dashboard

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze and monitor logistics operations across orders, drivers, hubs, and vehicles.

The dashboard provides operational insights into delivery performance, customer satisfaction, hub efficiency, driver performance, vehicle utilization, and maintenance activity.

## 🎯 Project Objectives

- Monitor overall logistics performance
- Analyze order volume and delivery performance
- Track On-Time Delivery Rate and Customer Satisfaction
- Evaluate hub performance and capacity utilization
- Analyze driver experience, ratings, and delayed deliveries
- Monitor vehicle activity and maintenance status
- Identify vehicle breakdown patterns
- Compare operational performance across selected periods

## 🛠️ Tools Used

- Power BI
- DAX

## 📊 Dashboard Sections

### 1. Main Dashboard

Provides a high-level overview of logistics operations, including:

- Total Orders
- On-Time Delivery Rate
- Customer Satisfaction (CSAT)
- Average Delivery Time
- Hub performance
- Driver performance
- Vehicle status and utilization

The dashboard also provides period-based comparisons with previous-month performance.

### 2. Drivers Overview

Analyzes driver-level performance through:

- Number of drivers
- Experience vs. ratings
- Delayed delivery rate by driver
- Individual driver delivery activity
- Driver-level monthly performance
- Driver selection for detailed analysis

### 3. Hubs Overview

Analyzes operational performance across six logistics hubs:

- Orders processed vs. hub capacity
- Hub performance ranking
- Processing time by day of the week
- Hub-level operational comparisons
- Monthly and yearly filtering

### 4. Vehicles Overview

Provides insights into the vehicle fleet through:

- Vehicle count
- Active vs. maintenance status
- Orders by vehicle
- Vehicle breakdowns by age
- Breakdown frequency by vehicle code
- Breakdown analysis by vehicle model
- Vehicle type and status filtering

## 📈 Key Metrics

- Total Orders
- On-Time Delivery Rate
- CSAT %
- Average Delivery Time
- Number of Hubs
- Number of Drivers
- Number of Vehicles
- Hub Performance
- Delayed Delivery Rate
- Vehicle Breakdown Count
- Active vs. Maintenance Vehicles
